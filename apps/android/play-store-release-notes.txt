<de-DE>
• Lokal-first Ansatz: Filme werden immer zuerst lokal auf dem Geraet gespeichert.
• Optionaler Supabase-Sync: Nur wenn Supabase URL + Key gesetzt sind, wird zusaetzlich mit Supabase synchronisiert.
• Ohne Supabase-Zugangsdaten bleibt die App voll lokal nutzbar.
• Technisches Release-Update: App-Version 1.1.0, Android versionCode auf 12 erhoeht.
</de-DE>
<en-US>
• Local-first approach: movies are always stored locally on device first.
• Optional Supabase sync: synchronization only runs when Supabase URL + key are configured.
• Without Supabase credentials, the app remains fully usable in local-only mode.
• Technical release update: app version 1.1.0, Android versionCode increased to 12.
</en-US>
